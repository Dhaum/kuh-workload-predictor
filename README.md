# 💊 KUH Workload Predictor (건국대학교병원 외래 출근부)

건국대학교병원 공식 외래 스케줄을 수합하여, 약국 조제 난이도를 사전에 예측하고 전체 의료진 출근 현황을 한눈에 파악할 수 있는 반응형 웹 애플리케이션입니다.

---

## 🌟 핵심 기능

1. **외래 전 23개 진료과 & 3단계 티어 필터**:
   * **Tier 1 (고난도 핵심 4개과)**: 신경과, 내분비대사내과, 심장혈관내과, 신장내과 (기본 활성화)
   * **Tier 2 (수술·특수관리 7개과)**: 종양혈액내과, 호흡기내과, 류마티스내과, 정형외과, 신경외과, 소화기내과, 흉부외과
   * **Tier 3 (일반·단기처방 12개과)**: 마취통증, 비뇨의학, 안과, 이비인후과, 피부과, 정신과 등
2. **간결한 이름·색상 전용 시각화**:
   * 불필요한 태그를 배제하고, 진료과별 고유 파스텔 톤 칩 안에 교수 이름만 깔끔하게 노출.
3. **📅 특정 날짜 전체 출근부 (Daily View)**:
   * 특정 날짜 클릭 시 오전/오후 출근 명단 전수 카드 뷰 + 실시간 교수명/진료과 검색 지원.
4. **Today & Now 자동 하이라이트**:
   * 대시보드 접속 시 오늘 요일 컬럼에 파란색 포커스 테두리 자동 점등.
5. **실시간 휴진 시각화**:
   * 당일/전일 휴진 교수는 취소선 + 반투명 + `[휴진]` 레드 뱃지 자동 표기.
6. **A4 1장 가로 인쇄 최적화 (Print CSS)**:
   * 브라우저에서 `Ctrl + P` 인쇄 시 필터/버튼을 숨기고 정확히 A4 가로 1장에 깔끔하게 출력.
7. **화면 최하단 최신화 시점 명기**:
   * `데이터 최신화: YYYY-MM-DD HH:mm:ss · 매일 아침 1회 자동 갱신`

## 🚀 빠른 로컬 실행 (내 PC에서 테스트)

외부 무거운 라이브러리 설치 없이 **Node.js 내장 모듈만으로 100% 무의존성 구동**됩니다.

### 1) 데이터 수합 및 캐시 생성
```bash
node src/cli.js
```
* 건국대병원 API에서 데이터를 수합하여 `public/data/schedule.json`을 생성합니다.

### 2) 로컬 개발 서버 실행 (웹 브라우저로 열기)
```bash
node src/cli.js --serve
```
* 브라우저에서 `http://localhost:3000` 접속 시 대시보드를 바로 사용할 수 있습니다.

## ☁️ Vercel 클라우드 배포 (데스크탑 꺼도 24시간 작동)

약국 직원들과 스마트폰, 태블릿, PC로 함께 열람하려면 Vercel에 배포합니다.

### 특징
* **데스크탑 전원 OFF 무관**: Vercel 글로벌 클라우드 서버에서 24시간 365일 독자적으로 구동됩니다.
* **당일 아침 1회 자동 수합 (On-Demand Daily Cache)**:
  * 매일 아침 직원이 처음 접속할 때 건대병원 API를 딱 1회 호출해 최신화하고,
  * 그 이후 접속은 0.01초 만에 Vercel 초고속 CDN 캐시로 응답하여 병원 서버 차단 위험이 0%입니다.

### 배포 방법 (GitHub 연동)
1. GitHub에 새 저장소(`kuh-workload-predictor`)를 생성하고 본 폴더 내용을 push합니다.
2. [Vercel 대시보드](https://vercel.com)에서 **`Add New Project`** 클릭 후 해당 GitHub 저장소를 선택합니다.
3. 별도 설정 변경 없이 **`Deploy`** 버튼을 누르면 1분 만에 `https://kuh-workload-predictor.vercel.app` 형태의 고유 URL이 발급됩니다!

## 📱 약국 직원 스마트폰 앱처럼 사용하기 (PWA 홈 화면 추가)

1. Vercel에서 발급된 URL을 약국 단체 카톡방에 공유합니다.
2. 각자 스마트폰 브라우저(사파리, 크롬 등)에서 접속합니다:
   * **아이폰(Safari)**: 하단 공유 버튼 클릭 $\rightarrow$ **[홈 화면에 추가]**
   * **갤럭시(Chrome)**: 우측 상단 메뉴($\vdots$) 클릭 $\rightarrow$ **[홈 화면에 추가]**
3. 스마트폰 바탕화면에 `💊 건대병원 외래` 아이콘이 생성되어 터치 1번으로 당일 외래 현황을 바로 확인할 수 있습니다.
