# 💊 건대외래일정 (KUH Workload Predictor)

건국대학교병원 공식 외래 스케줄을 수합하여, 약국 조제 난이도를 사전에 예측하고 전체 의료진 출근 현황을 한눈에 파악할 수 있는 반응형 웹 애플리케이션입니다.

---

## 🌟 핵심 기능

1. **외래 전 23개 진료과 & 대형 티어 다중선택 필터**:
   * **Tier 1**: 신경과, 내분비대사내과, 심장혈관내과, 신장내과 (기본 활성화)
   * **Tier 2**: 종양혈액내과, 호흡기내과, 류마티스내과, 정형외과, 신경외과, 소화기내과, 흉부외과
   * **Tier 3**: 마취통증, 비뇨의학, 안과, 이비인후과, 피부과, 정신과 등
   * 모바일에서도 터치하기 편한 대형 버튼으로 원하는 티어를 자유롭게 **다중 선택** 가능
2. **🔮 다음주 출근부 미리보기 (Week Switcher)**:
   * **`[ 이번주 ]`**와 **`[ 다음주 미리보기 ]`** 원클릭 전환 지원 (지연시간 0초).
3. **조건부 티어 점선 분할**:
   * 실제 출근 교수가 존재하는 티어 사이에만 가로 점선이 생성되어 깔끔한 시각화 보장.
4. **📅 특정 날짜 전체 출근부 (Daily View)**:
   * 특정 날짜 클릭 시 오전/오후 출근 명단 전수 카드 뷰 + 실시간 교수명/진료과 검색 지원.
5. **모바일 완벽 대응 (하이브리드 뷰)**:
   * 스마트폰 화면 폭(< 640px)에서는 요일 세그먼트 탭(`월 | 화 | 수 | 목[오늘] | 금`) + 당일 집중 카드 뷰로 자동 전환.
6. **실시간 휴진 시각화**:
   * 당일/전일 휴진 교수는 취소선 + 반투명 + `[학회휴진]`, `[정기휴가]`, `[오후반휴]` 등 레드 뱃지 자동 표기.
7. **화면 최하단 최신화 시점 명기**:
   * `데이터 최신화: YYYY-MM-DD HH:mm:ss · 매일 아침 1회 자동 갱신`

## 📱 약국 직원 스마트폰 앱처럼 사용하기 (PWA 홈 화면 추가)

1. Vercel에서 발급된 웹 링크를 약국 단체 카톡방에 공유합니다.
2. 스마트폰 브라우저(사파리, 크롬 등)에서 링크를 엽니다:
   * **아이폰(Safari)**: 하단 공유 버튼 클릭 $\rightarrow$ **[홈 화면에 추가]**
   * **갤럭시(Chrome)**: 우측 상단 메뉴($\vdots$) 클릭 $\rightarrow$ **[홈 화면에 추가]**
3. 스마트폰 바탕화면에 등록된 **전용 앱 아이콘**과 함께 **`건대외래일정`**이라는 이름으로 자동 생성되며, 브라우저 주소창 없는 전체화면 네이티브 앱 모드로 구동됩니다.
