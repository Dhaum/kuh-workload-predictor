<나라약국> 건대외래일정표

버전 1.2.4 · 빌드 2026.11.05

스마트폰 홈 화면 바로가기 (앱처럼 사용하기)

주소창 없는 전체화면 네이티브 앱 모드로 구동되어 터치 1번으로 바로 뜹니다.

아이폰 (Safari)

1. 화면 하단 중앙의 [공유] 아이콘(네모+화살표 ↑) 터치
2. 메뉴에서 [홈 화면에 추가] 선택 후 '추가'

갤럭시 (Chrome / 삼성인터넷)

1. 우측 상단 [ ⋮ ] 또는 하단 [ ☰ ] 터치
2. [홈 화면에 추가] (또는 현재 페이지 추가) 선택

외래 일정 확인 시 실무 주의사항
1
데이터 최신화 기준:

매일 아침 건국대병원 공식 전산을 1회 자동 수합하여 당일 출근부를 완성합니다. 최신 변경사항은 화면 하단의 [⟳ 새로고침]으로 즉시 재수합됩니다.

2
'당일마감' vs '실제 휴진' 구분:

• 당일마감: 외래 정상 진료 중 (온라인 예약만 마감된 상태이므로 처방전 정상 발행)
• [학회휴진] / [정기휴가] / [오후반휴]: 실제 외래 미진료 (취소선 및 붉은색 뱃지 표기)

3
당일 돌발 결진 안내:

응급 수술 등 병원 웹사이트에 미처 반영되지 않은 아침 돌발 휴진은 전산 반영이 다소 지연될 수 있으니 필요 시 내선 확인을 권장합니다.

개인 모바일 보안 및 안심 안내

본 앱은 100% 브라우저 격리 샌드박스에서만 구동됩니다. 사진, 연락처, 위치 등 기기 권한 요구가 일절 없으며, 개인정보 수집이나 스마트폰 용량을 차지하는 더미 파일이 전혀 남지 않으니 안심하고 등록하셔도 됩니다.
